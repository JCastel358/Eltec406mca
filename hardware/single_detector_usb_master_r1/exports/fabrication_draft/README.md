# Draft fabrication exporter

No manufacturing files have been generated by adding this exporter. Run it only after the board is fully routed and its saved native drill/place origin is **(12,115) mm**. The exporter refuses to change the board or manufacture a pass report.

Use the installed KiCad 10 Python, in this order, after the final board edit:

```powershell
& 'C:\Program Files\KiCad\10.0\bin\python.exe' hardware/single_detector_usb_master_r1/tools/validate_board.py --routing-run trial01
& 'C:\Program Files\KiCad\10.0\bin\python.exe' hardware/single_detector_usb_master_r1/tools/export_assembly.py
& 'C:\Program Files\KiCad\10.0\bin\python.exe' hardware/single_detector_usb_master_r1/tools/export_fabrication.py
```

Replace `trial01` with the actual imported routing-run folder name. The prerequisite validation must match the current PCB, native DRC JSON, every schematic/project/rule file, project library, routing handoff/import evidence and validation/Kelvin helper code. It must report zero violations, unconnected items and schematic-parity errors, with four copper layers, tracks, saved zone fills and zero native unconnected edges. The locked Kelvin seed must be retained with no extra conductor in its protected corridor. Configured exclusions and unexplained ignored DRC checks are rejected. Assembly output files and their hashes must match the same PCB. A stale or incomplete report fails before fabrication plotting starts.

The exporter copies the checked inputs into a private snapshot and performs another native DRC/parity check and protected-Kelvin verification there. All Gerber/drill commands read that snapshot. It does not refill zones, mutate CAD files, overwrite validation reports, upload anything or order parts. The existing project's outer-layer routing and through-via restrictions remain enforced. Only the reviewed unused length-tuning-profile check may be ignored.

Every successful run creates a new timestamp/hash directory ending in `_DRAFT`, containing metric X2 Gerbers for F.Cu, In1.Cu, In2.Cu, B.Cu, both solder masks, both silkscreens, both paste layers and Edge.Cuts. Unused silk/paste layers may be empty. It also creates separate native PTH/NPTH Excellon outputs with routed slots, PDF drill maps, a native drill report, coordinate evidence and a draft manifest ZIP.

Gerber and drill plotting explicitly use the saved drill/place origin; coordinates have positive X to the right and positive Y upward, without mirroring. The tool independently compares the native CLI's origin-relative placements with every assembly CPL body center and rotation. It also checks exported profile vertices and three noncollinear round-hole positions against native geometry. These checks do not replace a full CAM review of artwork, holes and slots.

The manifest hashes source inputs and every payload file except itself. A separate checksum receipt hashes the manifest and completed ZIP; neither checksum document contains its own recursive digest. Failed runs discard temporary output. Previous completed draft runs remain untouched and are identifiable by their source hash.

Four copper layers describe the CAD layer count. No fabricator stackup, copper weight, dielectric, finished thickness, surface finish, impedance or process capability is confirmed. Any generated Gerber-job stackup fields are unconfirmed design metadata. Native CAD checks do not prove electrical/thermal performance, fit, sourcing or assembly acceptance. Every package remains **DRAFT — NOT APPROVED FOR UPLOAD OR ORDER**.
